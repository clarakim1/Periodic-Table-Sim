# MakerWorld 업로드 문안 (초안)

**제목**: 실험 원소 주기율표 타일 17종 | Periodic Table Experiment Tiles

**설명**: 학생 과학 실험에 등장한 원소 17종을 실제 주기율표 위치에 맞춰 배열한 타일 세트입니다. 각 타일에는 원자번호와 원소 기호가 돌출되어 있고, QR 또는 링크로 3D 시뮬레이션과 연결됩니다.

**출력 설정 권장**: 레이어 0.12–0.2 mm, 서포트 없음, PLA. 두 가지 색상은 글자 시작 레이어(바닥 4 mm 이후)에서 필라멘트 교체.

**태그**: periodic table, chemistry, education, STEM, flame test

**업로드 체크**: 3MF 파일, 완성 사진 3장 이상(실제 출력물), 라이선스 선택(CC BY-NC 등). 프린트 프로필은 실제 출력 후 등록하세요.
